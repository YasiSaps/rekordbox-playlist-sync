Update rekordbox playlists in place — without re-syncing your whole USB.

rbsync updates an existing rekordbox 6 / 7 playlist from an M3U or M3U8 file. Only the changed tracks are added or removed, your cues and beatgrids stay put, and Sync Manager only copies what actually changed to your CDJ / XDJ USB.

The problem it fixes

Delete & re-import

rekordbox can import an M3U, but never update an existing playlist from one. Deleting and re-importing creates a new playlist, so Sync Manager tears the old one down and copies everything again. Slightly different file paths even create duplicate tracks without your cues.

rbsync

Compares the file with the playlist that is already in rekordbox and applies only the difference. Same playlist, same tracks, same cues — tested on a 2,000-file USB: +3 / −2 change → 3 files copied, 0 re-copied.

Features

Incremental

Adds new tracks, removes dropped ones, leaves the rest alone. Optional reorder to match the file.

Keeps your prep

Hot cues, memory cues, beatgrids, analysis, My Tags, ratings and colours are never touched.

Smart matching

Finds your tracks despite accents (NFC/NFD), letter case, file:// URLs, relative or Windows paths.

Safe

Dry run first, automatic backups, one-command undo, and it refuses to write while rekordbox is open.

No duplicates

Duplicate lines ignored; if a file is in your collection twice, the copy with the most cues is used.

Drag & drop

Drop a playlist on the macOS app, or right-click → Send to on Windows. Or script it with --json.

Install

Open Terminal and paste:

curl -fsSL https://raw.githubusercontent.com/YasiSaps/rekordbox-playlist-sync/main/install/install.sh | bash

Adds the rbsync command and the rbsync Playlist Updater drag-and-drop app in ~/Applications.

Install Python 3.9+ (tick “Add python.exe to PATH”), then open PowerShell and paste:

irm https://raw.githubusercontent.com/YasiSaps/rekordbox-playlist-sync/main/install/install.ps1 | iex

Adds the rbsync command and a right-click Send to → rbsync - Update rekordbox playlist entry.

Check everything with rbsync doctor, and try it risk-free with rbsync selftest (runs on a temporary copy of your library).

Usage

  1. Name the file after the rekordbox playlist: Peak Time.m3u8 updates Peak Time.
  2. Preview (safe while rekordbox is open):
    rbsync plan "Peak Time.m3u8"

  + add        10
  - remove     3   (removed from this playlist only)
  = unchanged  22
  3. Quit rekordbox, then apply:
    rbsync apply "Peak Time.m3u8"
  4. Open rekordbox and sync your USB — only the 10 new tracks are copied.

Undo any time with rbsync restore latest. Full command reference in the README.

Safety

  • Never touches music files and never adds or deletes tracks in your collection — only playlist membership.
  • Backup before every write, stored in Documents/rbsync/backups; rbsync restore puts it back.
  • Refuses to write while rekordbox is running, and verifies the playlist after writing.
  • Version gate: writing is enabled on rekordbox versions verified end-to-end; others need an explicit flag.

FAQ

Which rekordbox versions?Verified on rekordbox 7.2 (macOS). rekordbox 6 and other 7.x versions work in preview mode and can be enabled after running rbsync selftest. rekordbox 5 is not supported.
Is it official?No. It is an independent open-source project built on pyrekordbox, not affiliated with AlphaTheta / Pioneer DJ.
New tracks?rbsync only uses tracks already in your collection so they are properly analysed. Unknown files are listed — drag them into rekordbox once and run again.
Where do M3U files come from?Any app or script: rekordbox, Serato, Traktor, VirtualDJ or iTunes exports, VLC, foobar2000, playlist generators or AI assistants.
